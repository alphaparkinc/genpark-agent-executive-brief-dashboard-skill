Transforms raw telemetry, system metrics, and departmental status updates into high-impact executive decision briefs and KPI watchpoint summaries.

## Core Capabilities
- **Strategic Signal Extraction**: Automatically differentiates growth indicators from operational risk watchpoints.
- **Executive Summaries**: Produces concise bullet points ready for C-suite and leadership presentations.
- **Automated Recommendations**: Generates mitigation steps for deteriorating KPIs.

## MCP Server Integration
```bash
python mcp_server.py
```

### Available MCP Tools
- `generate_executive_brief`: Generate executive brief from metric dictionaries.
